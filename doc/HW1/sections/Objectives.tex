\section{Objectives}
%Brief description of the overall objectives of your system.
%What your system will be used for? Why is it important? What problems does it solve?

The primary objective of this project is to design and develop a user-friendly web application that enables a bar owner to sell products online.\\
The system should provide an intuitive interface for customers to browse items, place orders and complete the transactions. It aims to streamline order processing for the bar owner.
The application should be accessible across different devices and its goal is to enhance customer convenience while increasing the bar's sales and operational efficiency.
